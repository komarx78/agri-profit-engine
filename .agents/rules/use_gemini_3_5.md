# Geminiモデルのバージョン指定に関する絶対ルール

Google Gemini のAPIを利用するコード（Node.js, TypeScript等）を記述・修正する際、以下のルールを絶対に守ること。

- **禁止事項**: `gemini-1.5-flash` や `gemini-1.5-pro` などの古いモデル名を使用しないこと。
- **必須事項**: 常に最新の **`gemini-3.5-flash`** または `gemini-3.5-pro` を明示的に指定すること。
- **理由**: システムは2026年時点の最新環境で稼働しており、旧モデルを指定すると致命的な問題や非効率を招くため。
